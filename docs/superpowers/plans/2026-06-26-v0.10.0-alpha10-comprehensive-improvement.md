# v0.10.0-alpha10 Comprehensive Improvement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix all 12 issues found during project review — adapter agent sync, test coverage, recipe enrichment, and consistency polish — bringing `package-vuln-audit-skill` to a complete, consistent state across all 3 platforms.

**Architecture:** 4 priority-ordered batches. Batch 1 syncs 11 missing agent files to 3 adapters and unifies commands. Batch 2 adds 6 orphan tests to CI, creates the missing report fixture, and expands the workflow contract checker. Batch 3 enriches 8 generic recipes with domain-specific content. Batch 4 wires orphan tools, fixes template placeholders, and bumps versioning.

**Tech Stack:** Markdown agent/command definitions, JSON schemas, Python tool scripts, Bash shell scripts, JSON configuration files.

## Global Constraints

- All agent definitions must conform to the adapter-specific format (Claude Code: YAML frontmatter; OpenCode: plain `# heading`; Codex: inline in AGENTS.md).
- All 19 root agents must be represented in all 3 adapters.
- `run-tests.sh` must pass cleanly (`bash run-tests.sh` exit 0) after every batch.
- `enforce_workflow_contract.py --root . --out /tmp/check.json` must return `status: passed` after Batch 2.
- No recipe may contradict reference policies in `references/`.
- Version bump to `0.10.0-alpha10` only after all batches complete.
