# Validated PoC / Reproducer Policy

PoC means local reproducer testcase for authorized validation and regression testing. Generate it only for Validated Findings. Default disclosure is internal or maintainer-private. Public advisory output must not include reproducer scripts or testcase bytes unless public-after-fix is explicitly approved.

`Needs Manual Review` items receive manual validation plans and safe test methods, not formal executable PoC packages. They can be promoted to `Validated` only after stable local reproduction exists.
